# 使い方

## アプリケーションの起動

Soul Widgets Managerを起動するには、ターミナルからスタートアップスクリプトを実行します：

```bash
bash startup.sh
```

::: tip 注意
このスクリプトは自動的に `--ozone-platform-hint=wayland` フラグを追加します。これはChromeOSで透明度を正しくサポートするために重要です。
:::

## 基本操作

アプリケーションが実行されると、標準的なデスクトップと同じようにデスクトップオーバーレイを操作できます。

### コンテキストメニュー
デスクトップの背景を**右クリック**するとメニューが開きます。
- **アプリを追加:** URLまたはLinuxコマンドのショートカットを作成します。
- **ウィジェットを追加:** 利用可能なウィジェット（時計、メディアプレイヤーなど）を選択してデスクトップに配置します。
- **フォルダを追加:** ショートカットをグループ化するためのコンテナを作成します。
- **設定:** 設定パネルを開きます。

### アイテムの配置
- **ドラッグ＆ドロップ:** アイコンやウィジェットをクリックしたままにして移動します。
- **グリッドモード:** 設定で「グリッドモード」を有効にすると、アイテムがグリッドに合わせてきれいに整列します。

### マルチウィンドウモード
ChromeOSで仮想デスクトップを使用している場合：
1.  **設定**に移動します。
2.  **ウィンドウ数**を増やします。
3.  新しいオーバーレイウィンドウが表示されます。
4.  「概要モード」（3本指で上にスワイプ）に入り、新しいウィンドウを他の仮想デスクトップにドラッグします。

## セキュリティモード

**設定 → セキュリティとプライバシー** からセキュリティモードを選択できます。

- **厳格:** 許可リストにあるLinuxコマンドのみ実行可能。外部通信は許可ドメインのみ。
- **標準:** 既知の危険ドメインをブロックし、HTMLが多い入力をサニタイズ。
- **保護なし:** 制限なし（信頼できる環境向け）。

Linuxアプリを追加・編集すると、そのコマンドは自動的に許可リストへ追加されるため、厳格モードでも実行できます。

## ウィジェットのセットアップ

### 天気ウィジェット
天気ウィジェットを追加した後、ウィジェットを右クリックして **設定** を選択することで以下を行えます：
- お好みの天気プロバイダーの選択。
- 位置情報の設定（自動または手動）。
- 温度単位の変更。

### Gmailウィジェット
Gmailウィジェットを使用するには、独自のGoogle Cloud認証情報を用意する必要があります：
1.  [Google Cloud Console](https://console.cloud.google.com/) に移動します。
2.  新しいプロジェクトを作成し、**Gmail API** を有効にします。
3.  **OAuth 同意画面** を設定します（内部または外部）。
4.  **OAuth 2.0 クライアント ID** を作成します（アプリの種類は「ウェブ アプリケーション」または「デスクトップ アプリ」を選択）。
5.  デスクトップ上のウィジェット設定で、**クライアント ID** と **クライアント シークレット** を入力します。
6.  **ログイン** をクリックし、ブラウザで認証手順に従います。
