# Soul Widgets Managerとは？

Soul Widgets Managerは、ChromeOS (Linux/Crostini有効化済み) 専用に設計された、Electronベースの透明オーバーレイアプリケーションです。

## 課題
ChromeOSはWeb中心のオペレーティングシステムです。ブラウジングには最適ですが、ショートカットやファイル、ウィジェットを自由に配置できる従来の「アクティブデスクトップ」が存在しません。壁紙は基本的に静止画です。

## 解決策
Soul Widgets Managerは、壁紙の上かつアクティブなウィンドウの下に位置する透明なウィンドウを作成します。この「レイヤー」により、以下のことが可能になります：
- アイコンやショートカットを好きな場所に配置。
- 時計やメディアプレイヤーなどのインタラクティブなウィジェットを実行。
- フォルダを使ってワークスペースを整理。

これにより、WindowsやmacOSのようなデスクトップ体験をChromebookにもたらします。
