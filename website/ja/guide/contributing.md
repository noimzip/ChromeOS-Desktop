# 貢献について

コミュニティからの貢献を歓迎します！バグの修正、新しいウィジェットの追加、ドキュメントの改善など、どのような助けでも感謝します。

## 貢献方法

1.  **リポジトリのフォーク:**
    GitHubページで「Fork」ボタンをクリックして、自分のコピーを作成します。

2.  **ブランチの作成:**
    ```bash
    git checkout -b feature/amazing-feature
    ```

3.  **変更の実装:**
    機能や修正を実装します。

4.  **変更のコミット:**
    明確で簡潔なコミットメッセージを記述します。
    ```bash
    git commit -m 'feat: 新しい天気ウィジェットを追加'
    ```

5.  **ブランチへのプッシュ:**
    ```bash
    git push origin feature/amazing-feature
    ```

6.  **プルリクエストの作成:**
    元のリポジトリに移動し、ブランチを比較してプルリクエストを開きます。

## ガイドライン

- **バグ報告:** バグを見つけた場合は、[Issues](https://github.com/noimzip/Soul-Widgets-Manager/issues) をチェックして、すでに報告されていないか確認してください。報告されていない場合は、詳細な再現手順とともに新しいIssueを開いてください。
- **機能リクエスト:** 実装する前に、新しいアイデアについて議論するためにIssueを開いてください。
- **ライセンス:** 貢献することにより、コードがGPL-3.0ライセンスの下でライセンスされることに同意したことになります。
