# 機能

## 🧩 インタラクティブなウィジェット

Soul Widgets Managerには、生産性と美観を向上させるいくつかの組み込みウィジェットが用意されています。

### 時計ウィジェット
ユニークな12角形のデザインを採用した、スタイリッシュでモダンな時計です。一目で時間を確認できます。

### メディアプレイヤー
完全に機能するメディアコントローラーです。以下をサポートしています：
- **Linuxアプリ:** `playerctl` 経由で Spotify や VLC などのプレイヤーを制御。
- **Chromeブラウザ:** Chromeブラウザと統合し、YouTube や SoundCloud などのメディア情報を表示。
- **機能:** アルバムアート表示、シークバー、再生/一時停止、次へ/前へコントロール。

### GitHubコントリビューション
デスクトップ上で直接コーディング活動を追跡できます。コントリビューショングラフとストリーク統計を表示します。

### Googleカレンダー
埋め込みカレンダービューでスケジュールを把握できます。月、週、アジェンダ表示をサポートしています。

## 🚀 デスクトップ管理

### ショートカット
あらゆるものへのショートカットを作成できます：
- **Webアプリ:** URLへの直接リンク。
- **Linuxアプリ:** インストール済みLinuxアプリケーションの起動コマンド。
- **ファイルとフォルダ:** ローカルファイルへのクイックアクセス。

### フォルダ
ショートカットをカスタマイズ可能なフォルダにグループ化して、デスクトップを整理できます。

### カスタマイズ
**@m3e** ライブラリを使用して構築されており、UIはMaterial Design 3の原則に従っています：
- **テーマ:** ダーク、ライト、システムモード。
- **色:** 画像からの抽出を含むカスタムカラースキーム。
- **ビジュアル:** 調整可能なアイコン形状とブラー効果。

## 🖥️ システム連携

### マルチディスプレイ対応
デスクトップオーバーレイを表示する画面を選択できます。

### 仮想デスクトップ
複数のウィンドウをサポートしているため、各仮想デスクトップ（スペース）にデスクトップオーバーレイを配置できます。

### Chrome連携
コンパニオンChrome拡張機能がブラウザとLinuxコンテナの間のギャップを埋め、シームレスなメディア制御とデータ同期を実現します。
