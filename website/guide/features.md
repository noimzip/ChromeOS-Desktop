# Features

## 🧩 Interactive Widgets

Soul Widgets Manager comes with several built-in widgets to enhance your productivity and aesthetics.

### Clock Widget
A stylish, modern clock with a unique 12-sided design. It provides a clean way to check the time at a glance.

### Media Player
A fully functional media controller. It supports:
- **Linux Apps:** Controls players like Spotify, VLC, etc., via `playerctl`.
- **Chrome Browser:** Integrates with the Chrome browser to show media info from YouTube, SoundCloud, etc.
- **Features:** Album art display, seekbar, play/pause, next/prev controls.

### GitHub Contribution
Track your coding activity directly on your desktop. Displays your contribution graph and streak statistics.

### Google Calendar
Keep track of your schedule with an embedded calendar view. Supports Month, Week, and Agenda views.

## 🚀 Desktop Management

### Shortcuts
Create shortcuts for anything:
- **Web Apps:** Direct links to URLs.
- **Linux Apps:** Launch commands for installed Linux applications.
- **Files & Folders:** Quick access to your local files.

### Folders
Group your shortcuts into customizable folders to keep your desktop tidy.

### Customization
Built with the **@m3e** library, the UI follows Material Design 3 principles:
- **Themes:** Dark, Light, and System modes.
- **Colors:** Custom color schemes, including extraction from images.
- **Visuals:** Adjustable icon shapes and blur effects.

## 🖥️ System Integration

### Multi-Display Support
Choose exactly which screen should host your desktop overlay.

### Virtual Desktops
Support for multiple windows allows you to have a desktop overlay on each of your virtual desktops (spaces).

### Chrome Integration
A companion Chrome Extension bridges the gap between the browser and the Linux container, allowing for seamless media control and data syncing.
