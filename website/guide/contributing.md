# Contributing

We welcome contributions from the community! Whether it's fixing bugs, adding new widgets, or improving documentation, your help is appreciated.

## How to Contribute

1.  **Fork the Repository:**
    Click the "Fork" button on the GitHub page to create your own copy.

2.  **Create a Branch:**
    ```bash
    git checkout -b feature/amazing-feature
    ```

3.  **Make Changes:**
    Implement your feature or fix.

4.  **Commit Changes:**
    Write clear, concise commit messages.
    ```bash
    git commit -m 'feat: Add new weather widget'
    ```

5.  **Push to Branch:**
    ```bash
    git push origin feature/amazing-feature
    ```

6.  **Open a Pull Request:**
    Go to the original repository and open a Pull Request comparing your branch.

## Guidelines

- **Bug Reports:** If you find a bug, please check the [Issues](https://github.com/noimzip/Soul-Widgets-Manager/issues) to see if it's already reported. If not, open a new issue with detailed reproduction steps.
- **Feature Requests:** Feel free to open an issue to discuss new ideas before implementing them.
- **License:** By contributing, you agree that your code will be licensed under the GPL-3.0 License.
