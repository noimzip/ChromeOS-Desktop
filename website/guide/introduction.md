# What is Soul Widgets Manager?

Soul Widgets Manager is an Electron-based transparent overlay application designed specifically for ChromeOS (with Linux/Crostini enabled).

## The Problem
ChromeOS is a web-centric operating system. While it's great for browsing, it lacks a traditional "active desktop" where users can place shortcuts, files, and widgets. The desktop wallpaper is essentially a static image.

## The Solution
Soul Widgets Manager creates a transparent window that sits on top of your wallpaper but behind your active application windows. This "layer" allows you to:
- Place icons and shortcuts anywhere.
- Run interactive widgets like clocks and media players.
- Organize your workspace with folders.

It effectively brings a Windows or macOS-like desktop experience to your Chromebook.
