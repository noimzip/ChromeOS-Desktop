# Soul Widgets Manager への貢献

コミュニティからの貢献を歓迎します！バグの修正、新しいウィジェットの追加、ドキュメントの改善など、どのような形でもプロジェクトの向上に繋がります。

## 貢献の手順

### 1. リポジトリのフォーク
GitHub ページで「Fork」ボタンをクリックして、自分のアカウントにリポジトリをコピーします。

### 2. ブランチの作成
変更内容がわかるような名前でブランチを作成します：
```bash
git checkout -b feature/amazing-feature
```

### 3. 変更の実装
機能の追加、バグ修正、またはドキュメントの改善を行います。プロジェクトのコーディング規約に従ってください。

### 4. 変更のコミット
変更の内容とその理由を簡潔に説明したコミットメッセージを記述します：
```bash
git commit -m 'feat: 新しい天気ウィジェットを追加'
```

### 5. フォークしたリポジトリにプッシュ
```bash
git push origin feature/amazing-feature
```

### 6. プルリクエストの作成
GitHub 上の元のリポジトリに移動し、プルリクエストを開きます。変更内容と、それがプロジェクトにどのように役立つかを明確に記述してください。

## ガイドライン

- **バグ報告:** 新しい Issue を作成する前に、すでに同じ内容が報告されていないか [Issues](https://github.com/noimzip/Soul-Widgets-Manager/issues) を検索してください。報告されていない場合は、詳細な再現手順を含めて報告してください。
- **機能リクエスト:** 実装を始める前に、新しいアイデアについて議論することを推奨します。Issue を作成して対話を開始してください。
- **コードスタイル:** **Standard JS** に準拠しています。既存のコードベースと一貫性のある、クリーンなコードを心がけてください。
- **UI/UX:** UI に変更を加える場合は、付属の `@m3e` ライブラリを使用し、**Material Design 3** の原則に従ってください。
