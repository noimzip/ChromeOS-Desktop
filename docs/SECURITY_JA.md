# セキュリティポリシー

## 脆弱性の報告方法

プロジェクト内でセキュリティ上の脆弱性を発見した場合は、**公開された Issue を作成しないでください**。代わりに、以下の方法で報告してください：

1. メンテナへの直接連絡
2. GitHub のプライベートセキュリティアドバイザリ機能（利用可能な場合）

報告を確認次第、修正に向けたスケジュールをお知らせします。

## Electron セキュリティのベストプラクティス

Soul Widgets Manager では、攻撃対象領域（アタックサーフェス）を最小限に抑えるために Electron のセキュリティベストプラクティスに従っています：

- **コンテキストの分離 (Context Isolation):** 有効。レンダラープロセスは Electron の内部 API や Node.js に直接アクセスできません。
- **サンドボックス (Sandbox):** すべてのレンダラープロセスで有効。
- **Node Integration:** レンダラープロセスでは無効。
- **ナビゲーション制限:** アプリ内ウィンドウでの予期しない外部 URL への遷移を防止しています。外部リンクはシステムのデフォルトブラウザで開かれるよう強制されます。

## セキュリティモード

Soul Widgets Manager は3つのセキュリティモード（Strict / Standard / None）を提供しています。これらは入力のサニタイズ、ネットワーク制限、セッションの永続性に影響します。

- **Strict (厳格):** 許可された外部ドメインのみ通信可能。Linux コマンドはホワイトリストに登録されているもののみ実行可能。
- **Standard (標準):** 既知の悪質なドメインがブロックされる。HTML 形式の入力はサニタイズされる。
- **None (なし):** 制限なし（開発者または信頼できる環境のみ）。

設定は「設定」ダイアログの「セキュリティとプライバシー」から変更可能です。

## ローカル通信 (WebSockets)

- アプリケーションは **ポート 25600** で WebSocket サーバーを開きます。
- このサーバーは `localhost` にバインドされており、ローカルの Chrome 拡張機能との通信のみを目的としています。
- 注意：システム上の他のローカルアプリケーションも理論的にはこのポートに接続可能です。信頼できるローカル環境でのみ実行することを推奨します。

## コマンドの実行 (`exec`)

- このアプリケーションでは、ユーザーが Linux コマンドを実行するショートカットを作成できます。
- **警告:** 信頼できないソースからのコマンドや URL を追加しないでください。悪意のあるコマンドを実行すると、Linux コンテナ (Crostini) やファイルが侵害される恐れがあります。
- ファイルやフォルダを開く際には `xdg-open` を使用しており、システムのデフォルトハンドラに依存しています。

## データのプライバシーと保存

### 機密情報
- **OAuth トークン:** Gmail ウィジェット等の機能で使用される OAuth2 アクセストークンおよびリフレッシュトークンは、ブラウザの `localStorage` に保存されます。これらは Google API との通信に使用されます。
- **クライアント資格情報:** Google Cloud のクライアント ID およびシークレットも `localStorage` に保存されます。
- **位置情報:** 天気ウィジェットは緯度と経度を保存します。プライバシー保護のため、これらの座標は保存前に小数点以下2桁（精度約1km）に丸められます。

ChromeOS および Linux コンテナのセキュリティを適切に維持してください。`userData` ディレクトリにアクセスできるユーザーは、理論上これらのトークンを取得できる可能性があります。

## Chrome 拡張機能

- 拡張機能は「デベロッパーモード」で読み込まれます。
- 必ず公式のソース/リポジトリから読み込むようにしてください。
- 拡張機能は、デスクトップウィジェットと同期するために、様々なウェブサイトからメディアのメタデータにアクセスする権限を必要とします。
