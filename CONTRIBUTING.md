# Contributing to Soul Widgets Manager

We welcome contributions from the community! Whether it's fixing bugs, adding new widgets, or improving documentation, your help is appreciated.

## How to Contribute

### 1. Fork the Repository
Click the "Fork" button on the GitHub page to create your own copy of the project.

### 2. Create a Branch
Create a descriptive branch name for your changes:
```bash
git checkout -b feature/amazing-feature
```

### 3. Make Changes
Implement your feature, fix a bug, or improve documentation. Please adhere to the project's coding conventions.

### 4. Commit Your Changes
Write clear, concise commit messages that explain the "why" behind the change:
```bash
git commit -m 'feat: add a new weather widget'
```

### 5. Push to Your Fork
```bash
git push origin feature/amazing-feature
```

### 6. Open a Pull Request
Go to the original repository on GitHub and open a Pull Request. Provide a clear description of your changes and why they are beneficial.

## Guidelines

- **Bug Reports:** Before opening a new issue, please search the existing [Issues](https://github.com/noimzip/Soul-Widgets-Manager/issues) to see if it has already been reported. If not, use the bug report template and provide detailed reproduction steps.
- **Feature Requests:** We encourage discussing new ideas before implementation. Open an issue to start a conversation.
- **Code Style:** We follow **Standard JS**. Please ensure your code is clean and consistent with the existing codebase.
- **UI/UX:** For any UI changes, follow **Material Design 3** principles using the included `@m3e` library.
